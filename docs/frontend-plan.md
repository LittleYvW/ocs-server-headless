# Web UI 执行计划

> 实施状态（2026-10-24）：第 1–5 项的主要流程与第 6 项的同源托管、构建脚本、响应式和真实浏览器回归已完成。设计采用深色灵动线条方向：近黑底、1px 发丝线、细线图标与单一强调色，渐变、光效和解释性文本克制使用。实现说明、客户端约束与部署细节见 [Web 控制台](web-ui.md)。以下保留原始范围、数据流与验收标准。

## 目标与边界

下一阶段实现可在普通浏览器中使用的管理界面，连接现有 `/api/v1` 后端，完成实例配置、无头运行管理和诊断。此文档规定功能、数据流、实施顺序与验收；视觉采用深色灵动线条方向，具体令牌、布局与交互约束记录在 [Web 控制台](web-ui.md)，不在本计划内重复。

当前后端只提供单管理员令牌认证。前端不承担浏览器进程监管、文件系统操作或密钥管理；不继续使用 Electron IPC、`remote`、同步 Node 调用和桌面版 `electron-store`。原桌面渲染层已在迁移完成后移除，需要参考历史业务字段时查阅 Git 历史。

## 实施顺序

### 1. 建立浏览器端基础与接口客户端

- 创建或改造独立前端入口；移除 Electron、Node 核心模块和桌面环境假设，加入 workspace 时不使后端构建依赖前端。
- 建立版本化 API 客户端，统一处理 `{data}`、`{error}`、请求取消、网络错误、401、403、409 和服务端错误。
- 使用当前页面同源地址作为默认 API 根路径；开发环境通过代理或显式配置连接后端。来源配置遵守后端 `OCS_ALLOWED_ORIGINS`。
- 定义 BrowserProfile、RuntimeState、UserScript、自动化程序配置、页面、下载和事件的 TypeScript 类型，优先从共享契约生成或导入，避免字段漂移。
- 提供管理员令牌输入、连接验证、退出并清除本地令牌。默认只在当前会话持有凭据；如提供记住选项，需要明确告知存储位置和清除方式。不得在查询参数、日志、分析服务或自动化页面中传递令牌。

验收：原生浏览器中无 Electron / Node 依赖错误；有效令牌可连接；无效令牌提示重新认证；403 能指向来源配置问题；退出后终止所有事件请求。

### 2. 实例配置与运行管理

- 提供实例列表和详情、新建、编辑、删除，展示配置与运行状态；删除前说明 profile / 下载保留语义。
- 对接启动、停止、重启，处理 starting / stopping 状态与重复请求冲突；编辑和删除配置前先停止实例；脚本代码更新则在实例重启后生效。
- 通过服务信息显示容量，并根据实际后端 409 响应处理并发上限。
- 表单使用后端内置自动化程序定义渲染字段，支持 required、visibleWhen、类型、范围和选项，保持前后端校验一致。
- 对密码字段保留 `***` 的原值语义；提供显式修改操作，避免保存表单时清空已有密码。

验收：实例 CRUD 在刷新和服务重启后保留；切换管理客户端不影响浏览器运行；重复启动、容量满、浏览器启动失败、配置非法均有明确状态；不以 running 误报自动化已完成。

### 3. 页面查看与受限操作

- 对接页面列表和页面选择；重启后废弃旧 pageId 并重新拉取。
- 对接导航、点击、填写，限制前端输入长度并呈现服务端参数错误；不增加任意 JS / CDP / 文件系统执行入口。
- 通过认证请求读取截图为 Blob；切换实例、页面、离开页面时取消过期请求并释放 Object URL。
- 仅在用户需要查看的实例上刷新截图；允许暂停并防止并发轮询累积。截图策略由实现根据性能测试确定。
- 列出实例下载并通过认证请求获取文件，使用服务端返回的文件名，处理大文件、失败与取消。

验收：多页面选择和实例重启无串图；截图请求失败可恢复；停止实例后轮询停止；操作和下载保持在所属实例范围。

### 4. 用户脚本与平台设置

- 提供普通 JS 用户脚本列表、详情、新建、编辑、启停和删除，维护实例的脚本关联。
- 对 URL 匹配表达式做前端预检，并说明这里只支持普通页面 JS，不能直接宣称兼容油猴 / 脚本猫 `GM_*` API。
- 保存脚本或关联变更后提示实例重启生效；删除仍被引用的脚本时依据后端约定处理冲突。
- 对接 `settings.ocs` 的业务配置编辑，并按对象整体替换语义提交完整值；监听地址、令牌、密钥、浏览器和扩展路径由部署管理员配置，不在普通设置中暴露。

验收：仅关联且启用、URL 匹配的脚本被注入；修改后按重启语义生效；不会将不支持的脚本管理器能力展示为已实现。

### 5. 事件与诊断

- 使用支持 Bearer 头的 fetch SSE 客户端；解析跨网络块切分的事件，不把 token 加入 URL。
- 事件连接支持取消、心跳、断线重试和退避；重新连接后重新获取当前状态，不依赖内存事件缓存永久回放。
- 显示实例状态、自动化结果和近期服务事件，支持实例过滤和有限条数，避免前端无限增长。
- 提供连接中断、认证失效、浏览器异常退出和服务重启的恢复流程；对用户输入和事件内容安全转义。

验收：断网、服务重启、标签页休眠后能够恢复；过期请求不覆盖新状态；日志和错误反馈不泄露密码、填充值或令牌。

### 6. 集成、部署和回归

- 开发环境前后端可独立启动；生产构建明确静态资源托管位置和 API 反向代理规则，采用同源部署作为默认方案。
- 新增前端构建和检查脚本；后端无前端资源时仍能独立构建、测试和运行。
- 针对关键用户流程编写浏览器端端到端用例：连接认证、实例 CRUD、启停、配置、截图、脚本、下载、事件重连和错误恢复。
- 在默认 WSL 服务端与 Windows 普通浏览器组合下验收，同时覆盖 Linux 无 DISPLAY / WAYLAND_DISPLAY 环境。为所有部署命令补充文档。

验收：从全新拉取、安装、构建到浏览器管理的流程可复现；前端不依赖 Electron；服务端持续运行和数据持久化不依赖任何管理页面开启。

## 实施记录（2026-10-24）

- 基础与接口客户端：独立 `packages/web-ui` 工作区，Vue 3 + Vite + TypeScript；同源 API 客户端统一处理 `{data}`、`{error}`、取消、网络错误、401/403/409；令牌默认 `sessionStorage`，可选 `localStorage` 并在设置页清除。
- 实例管理：列表、详情、新建、编辑、删除、启动、停止、重启、容量与 409 反馈；自动化表单由 `/automation-scripts` 生成，支持 `visibleWhen`、必填、范围、选项与密码 `***` 原值语义。
- 页面与下载：页面列表、受限导航/点击/填写、认证截图、可暂停轮询、Object URL 释放、下载列表、带进度与取消的认证下载。
- 脚本与设置：用户脚本 CRUD、启停、匹配预检、引用冲突提示；`settings.ocs` JSON 编辑按整体替换提交。
- 事件与诊断：带 Bearer 的 fetch SSE、心跳看门狗、指数退避、重连后重新同步、有限事件缓存与过滤；实例状态、自动化结果与近期事件可展开查看。
- 集成与回归：`pnpm build:web` 输出 `packages/server/web` 并由服务端同源托管（`OCS_WEB_DIR` 可覆盖），后端在缺少前端产物时独立运行；同源 CSP、静态缓存与 API 404 行为有测试覆盖。
- 真实浏览器回归：`packages/web-ui/tests/console.e2e.cjs` 使用临时后端与本地 fixture，覆盖认证、SSE 重连、条件字段、实例生命周期、截图、操作、下载、自动化、事件、退出与来源 403；CI 在安装 Chromium 后运行 `pnpm test:web`。
- 未改变的后端边界：单管理员令牌、无多租户；页面操作仍只有导航/点击/填写/截图；不提供 `GM_*`、扩展商店、OCR 或任意 Node/文件系统执行。

## 暂不纳入前端交付的能力

多租户和角色管理、桌面数据自动迁移、第三方服务端自动化代码执行、OCR 二进制安装、扩展商店自动下载与脚本管理器安装器需要独立后端设计和接口支持，应在后续明确范围后排期。当前计划不以虚拟按钮或客户端本地逻辑代替尚不存在的后端能力。
